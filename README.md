# Student Grade Manager

A simple Python application designed to manage student grades and calculate academic averages.

## Features

* Enter student information.
* Add multiple grades.
* Validate grades (0–20).
* Calculate the average automatically.
* Determine whether the student passed or failed.

## Technologies Used

* Python 3
* Lists
* Loops
* Conditional Statements
* Functions and Built-in Methods

## How It Works

1. Enter the student's name.
2. Choose the number of grades.
3. Enter each grade.
4. The program calculates the average.
5. A student report displays the grades, average, and final result.
